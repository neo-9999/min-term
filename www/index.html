Automating Incremental Backups with systemd Timers

Replacing legacy cron jobs with systemd timers for better logging and failure visibility.

While cron works fine for simple scripts, systemd timers integrate cleanly with journalctl and handle missed runs automatically via Persistent=true.

[Unit]
Description=Daily backup timer

[Timer]
OnCalendar=*-*-* 03:30:00
Persistent=true

[Install]
WantedBy=timers.target

After placing the unit files in /etc/systemd/system/, reload the daemon and enable the timer with systemctl enable --now backup.timer.

Minimal Static Site Caching Headers in Nginx

A quick reference for setting clean cache-control headers on static assets without overcomplicating the config.

For small static sites, separating HTML revalidation from long-lived asset caching keeps pages fresh while avoiding unnecessary transfers:

location ~* \.(css|js|svg|png|woff2)$ {
    expires 30d;
    add_header Cache-Control "public, immutable";
}

Always test the configuration with nginx -t before reloading.

Debugging MTU and Fragmentation Issues on IPv6

Notes on using tracepath and ping with the do-not-fragment flag to spot path MTU bottlenecks.

When connections stall on specific hosts while small requests succeed, Path MTU Discovery (PMTUD) is often blocked by an intermediate firewall dropping ICMPv6 Packet Too Big messages.

ping -6 -M do -s 1452 example.com

Stepping down the payload size in increments of 8 or 16 bytes quickly reveals the effective ceiling on the link.
